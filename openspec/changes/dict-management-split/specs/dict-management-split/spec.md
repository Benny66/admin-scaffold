# Spec: dict-management-split

字典管理页面从「类型列表 + 弹窗查看字典项」重构为左右分栏交互，并为字典项新增 Excel 导入导出（单类型/全量两层次、按 value 覆盖合并），仅改交互与接口形态，不改数据模型与权限码。

## ADDED Requirements

### Requirement: 左侧展示分页的字典类型列表

页面 SHALL 呈现左右分栏。左栏 MUST 以分页表格展示字典类型，每页 10 条，支持按关键字（字典名/编码）搜索过滤；点击左栏任一行 MUST 选中该类型并使右栏切换到其字典项。左栏行在 hover 时 MUST 展示编辑与删除操作图标，编辑/删除作用于该字典类型。删除字典类型 MUST 沿用现有级联语义，其下字典项一并删除。

#### Scenario: 左栏分页与搜索

- **WHEN** 用户在第 1 页关键字搜索框输入关键字并点击「查询」
- **THEN** 左栏刷新为该关键字匹配的字典类型分页结果，页码回到第 1 页

#### Scenario: 点击左栏行使右栏切换

- **WHEN** 用户点击左栏某一行（如「订单状态」）
- **THEN** 该行高亮为当前选中类型，右栏标题与列表切换为该类型的字典项

#### Scenario: 左栏翻页不重置右栏选中

- **WHEN** 用户已选中「订单状态」后翻动左栏分页
- **THEN** 右栏仍保持显示「订单状态」的字典项，不受左栏页码变化影响

#### Scenario: hover 显示类型操作

- **WHEN** 用户将鼠标悬停在左栏某行上
- **THEN** 该行出现编辑与删除图标；点击编辑弹出字典类型编辑表单，点击删除弹出确认并级联删除其字典项

#### Scenario: 左栏新增字典类型

- **WHEN** 用户点击左栏「新增字典类型」
- **THEN** 弹出新建表单，保存后左栏刷新且新类型生效

### Requirement: 右侧展示当前类型的字典项并支持维护

右栏 MUST 展示当前选中类型的字典项分页列表，标头显示类型名，并提供「新增」与行内「编辑/删除」操作。右栏工具条 MUST 提供导入、导出两个层次的操作按钮（见下述导入导出 Requirement）。

#### Scenario: 右侧展示当前类型字典项

- **WHEN** 用户选中某类型后查看右栏
- **THEN** 右栏列表展示该类型全部字典项（分页 10 条/页），表头含标签、值、排序、状态、备注、操作

#### Scenario: 右栏新增/编辑/删除字典项

- **WHEN** 用户在右栏新增、编辑或删除一个字典项
- **THEN** 操作成功作用于当前选中类型，列表即时刷新

### Requirement: 字典项 Excel 导出（单类型与全量）

系统 SHALL 支持将字典项导出为 Excel（xlsx）文件，提供单类型导出与全量导出两个层次。单类型导出 MUST 只包含当前选中类型的所有字典项；全量导出 MUST 包含全部字典类型，每类型占用一个 sheet（sheet 名用类型中文名，冲突或非法时回退编码）。导出列头 MUST 固定为 `label | value | sort | status | remark`。导出操作 MUST 鉴权为 `dict:view`。

#### Scenario: 导出当前选中类型

- **WHEN** 用户点击右栏「导出」且当前选中「用户状态」
- **THEN** 浏览器下载一个 xlsx 文件，内容为该类型全部字典项，列头为 label/value/sort/status/remark

#### Scenario: 导出全部类型为多 sheet

- **WHEN** 用户点击「导出全部」
- **THEN** 下载的 xlsx 中每个字典类型对应一个 sheet，sheet 名取类型中文名（冲突或非法字符时回退编码）

#### Scenario: 无权限用户请求导出

- **WHEN** 无 `dict:view` 权限的用户触发导出
- **THEN** 后端返回 403，前端不产生下载

### Requirement: 字典项 Excel 导入（按 value 覆盖合并）

系统 SHALL 支持将 Excel 文件导入到当前选中类型。导入 MUST 按 `value` 覆盖合并：value 已存在则更新其 label/sort/status/remark，value 不存在则新增；文件未涉及的既有字典项 MUST 保留。导入 MUST 鉴权为 `dict:create`。导入完成后 MUST 返回新增条数、更新条数；导入文件列头 MUST 与导出约定一致（含模板可空）。

#### Scenario: 导入覆盖合并

- **WHEN** 用户向「用户状态」导入一个含 value=1 更新、value=3 新增的 xlsx
- **THEN** value=1 的项被更新，value=3 的项被新增，其余既有项保留，接口返回新增/更新统计

#### Scenario: 导入模板可用

- **WHEN** 用户下载当前类型的导入模板（含表头、无数据行）后填写并上传
- **THEN** 按模板列头正常解析并导入，不发生列名错位

#### Scenario: 无权限用户请求导入

- **WHEN** 无 `dict:create` 权限的用户触发导入
- **THEN** 后端返回 403，不写入任何字典项
