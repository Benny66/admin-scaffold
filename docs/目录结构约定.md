# 目录结构约定

基座采用三端 monorepo 结构，各端目录职责如下。

## backend/（Go 后端）

```
backend/
├── main.go               # 程序入口：初始化配置、数据库、路由、启动
├── go.mod
├── config/
│   ├── config.go         # 三层配置体系（默认值 → YAML → 环境变量）
│   └── config.example.yaml
├── database/
│   └── database.go       # SQLite/MySQL 双驱动 + 自动迁移 + 基础数据
├── models/               # 数据模型（纯结构 + GORM tag）
├── middleware/           # JWT/CORS/日志/RBAC 中间件
├── services/             # 业务逻辑层（不碰 gin.Context）
├── controllers/          # 控制器层（校验 + 调 service + 响应）
├── router/
│   ├── router.go         # 路由注册
│   └── serve.go          # 前端产物静态托管（dist/dist-mobile 存在时启用 + SPA 回退）
└── utils/                # 工具（响应/JWT/加密/分页）
```

### 前端产物托管（部署态）

后端会在启动时检测工作目录下的前端构建产物，存在则自动托管：

| 产物目录 | 挂载路径 | 说明 |
|---|---|---|
| `backend/dist/` | `/` | 桌面端（Web 前端） |
| `backend/dist-mobile/` | `/m/` | 移动端 H5 |

- **SPA 回退**：桌面端产物存在时，非 `/api/`、非 `/static/` 前缀的未命中路径会回退到 `dist/index.html`，支持前端 history 路由刷新。
- **优雅降级**：`dist/`、`dist-mobile/` 不存在时，后端保持纯 API 服务（开发态 `go run` 行为不变，前端仍用 `vite dev`）。
- 产物由打包脚本（`scripts/package.sh`，见 `add-multi-platform-packaging`）生成。

## frontend/（Web 前端）

```
frontend/src/
├── main.js               # 入口：注册 Pinia/Router/Element Plus
├── App.vue
├── api/
│   └── index.js          # 所有 API 定义
├── assets/styles/        # 全局样式
├── layout/
│   └── Layout.vue        # 主布局（侧边栏+顶栏+内容区）
├── router/
│   └── index.js          # 路由 + 守卫
├── stores/               # Pinia 状态（统一 stores/）
│   └── app.js
├── utils/
│   └── request.js        # axios 封装 + 拦截器
└── views/                # 页面
    ├── Login.vue
    └── system/           # 系统管理五件套
        ├── user/
        ├── role/
        ├── permission/
        ├── dict/
        └── log/
```

## mobile/（移动端）

```
mobile/src/
├── main.js
├── App.vue
├── api/
├── router/
├── stores/               # 移动端状态（统一 stores/，与前端一致）
├── utils/request.js
└── views/
    ├── Login.vue
    ├── Home.vue
    └── Mine.vue
```

## 新增业务模块的落位规则

1. **后端**：`services/xxx_service.go` → `controllers/xxx.go` → `router.go` 注册。
2. **前端**：`views/<domain>/` 建页面 → `api/index.js` 加接口 → 需要时加 `router`。
3. **移动端**：`views/` 建页面 → `api/index.js` 加接口。

## 通用规则

- 根目录 `docs/` 放规范文档，`AGENTS.md` 放 AI 开发约束。
- 运行时产物（`*.db`、`dist/`、`node_modules/`）一律不进版本库。
